# The Ubuntu "ISO" is only 305 KB

**Symptom:** The download finished instantly and the file is tiny.

**Cause:** I downloaded a `.torrent` file, not the ISO. The real ISO is about 3.8 GB.

**Fix:** Download the ISO directly from `https://releases.ubuntu.com/24.04/`. Get the **Ubuntu Server 24.04.5 LTS AMD64** file.

> ✅ The file is about 3.8 GB.
